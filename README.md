## Nawaari Daily Rate Calculator (TJM)

**Description**: Nawaari is a web application that allows freelancers or consultants to easily calculate their Daily Rate (TJM), considering various factors such as monthly salary, charges, and vacation time. This calculator helps freelancers set a fair price for their services and better understand their income.

## Features 🛠️

Calculation of TJM based on gross monthly salary, the number of working days per month, charges, and vacation time.
Simple and intuitive user interface.
Real-time results displayed as the user inputs data.
Customization options based on the freelancer's status (contract type, specific charges).
